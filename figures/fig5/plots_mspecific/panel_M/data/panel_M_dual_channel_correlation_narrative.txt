PANEL M: GABA sign-inverter pool routing vs E/I balance (converging evidence)
=============================================================================

DESIGN
------
Three panels per channel test ONE central claim from complementary angles:

  A. SI-routed fraction of inhibitory path strength vs (exc - inh)/(exc + inh).
     Tests whether subtypes with relatively MORE of their inhibition delivered
     via the GABA sign-inverter pool sit at MORE inhibitory E/I balances.
  B. SI inhibitory path strength vs TOTAL inhibitory path strength per subtype.
     Tests whether the SI pool actually contributes a measurable slice of the
     total inhibition (not a marginal pathway).
  C. Counterfactual dose-response: SI-routed inhibitory fraction vs |Delta E/I|
     after zeroing every inhibitory path that traverses any SI pool member.
     Tests the mechanistic prediction that subtypes routing more of their
     inhibition through the SI pool should shift more when the pool is
     silenced.

n = 16 mAL_m subtypes per channel. Pool (n = 11) = AN05B021, AN05B023a, AN05B023b, AN05B023c, AN05B023d, AN05B025, AN05B035, AN05B050_a, IN05B002, IN05B011a, IN05B011b.

STATISTICS
----------
ppk23 (male contact pheromone)
  A (SI-inh fraction -> E/I): R^2 = 0.211, p_OLS = 0.0736, Pearson r = -0.459 (p = 0.0736), Spearman rho = -0.512 (p = 0.0427)
  B (SI inh strength vs total inh strength): R^2 = 0.745, slope = 0.858, Pearson r = 0.863 (p = 1.67e-05)
  C (SI-inh fraction -> |Delta E/I| counterfactual): R^2 = 0.477, p_OLS = 0.00306, Pearson r = 0.691 (p = 0.00306), Spearman rho = 0.621 (p = 0.0103)
ppk25 (female contact pheromone)
  A (SI-inh fraction -> E/I): R^2 = 0.300, p_OLS = 0.0281, Pearson r = -0.548 (p = 0.0281), Spearman rho = -0.485 (p = 0.0567)
  B (SI inh strength vs total inh strength): R^2 = 0.815, slope = 0.930, Pearson r = 0.903 (p = 1.68e-06)
  C (SI-inh fraction -> |Delta E/I| counterfactual): R^2 = 0.706, p_OLS = 4.57e-05, Pearson r = 0.840 (p = 4.57e-05), Spearman rho = 0.865 (p = 1.54e-05)

INTERPRETATION
--------------
Panel A is the original, single-scatter view (borderline at n = 16). Panels
B and C add the two mechanistic checks: B confirms the SI pool is not a
marginal pathway, and C confirms a clear dose-response between SI routing
and counterfactual E/I shift. Panels A + B + C together support the claim
that the GABA sign-inverter pool is the dominant lever shaping mAL_m E/I
balance on both contact-pheromone channels.
